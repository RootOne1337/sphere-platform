# Синхронизация внешнего вида по аккаунту

14 ноября 2026. Первый этап CHAT-31 реализован в `0f228e45`. В панели
«Внешний вид» сохраняются палитра, плотность, акцент, размер текста, режимы
бокового меню и инспектора, стиль поверхности, интенсивность стекла и движение.
Подтверждённый профиль загружается при входе или перезагрузке. Кэш доступен
для того же аккаунта и организации. Переключение фокуса не отправляет запись.

API `GET/PATCH /api/v1/user-preferences/me` определяет владельца из текущей
сессии. `PATCH` принимает изменённые поля и проверяет `If-Match` по текущему
`ETag`. При конфликте или неподтверждённой записи правки остаются видимыми
в открытой вкладке. Кнопка «Загрузить сохранённые настройки» заменяет их
серверной версией. Старый локальный профиль автоматически не импортируется.
[Руководство по веб-интерфейсу](../../operations/WEB-ENTRY-GUIDE.md).

## Проверки на отдельном стенде

- PostgreSQL 15 прошёл полную цепочку Alembic. На отдельной базе с существующим
  пользователем проверены upgrade, downgrade и повторный upgrade. Атрибуты
  пользователя, его статус и хеш пароля совпали до и после.
- API в режиме production работал с Redis и ограниченной ролью PostgreSQL.
  Две независимые HTTP-сессии одного аккаунта читали один профиль. Другой
  аккаунт той же организации и аккаунт другой организации сохранили свои
  настройки. Проверены пустой контекст RLS и отказ записи в другую организацию.
- При конкурентном создании и конкурентном обновлении две транзакции дошли
  до PostgreSQL. В каждой паре одна запись завершилась `200`, другая `412`.
  Также проверены отсутствие авторизации, отсутствующий и ошибочный `If-Match`,
  пять ошибок валидации, CORS и сохранение `ETag` при неизменном значении.
- В четырёх отдельных контекстах Chromium проверены две сессии одного
  аккаунта и два других аккаунта. Первая сессия сохранила размер текста
  (`200`, `ETag: "ui-1"`). Устаревшая запись во второй получила `412`.
  Кнопка загрузки серверной версии восстановила подтверждённый размер,
  а полная перезагрузка сохранила его. Другой аккаунт той же организации
  и аккаунт другой организации сохранили исходный размер. Ошибок выполнения
  страницы не было.
- Прошли 33 теста Jest, TypeScript, тест API под ограниченной ролью PostgreSQL,
  Ruff, целевой mypy, проверка RLS и генерация документации API.
