# Файлы Android и VPN на PH025

14 ноября 2026. Файловый обмен реализован в вебе, API и Android-агенте.
На действующем пилоте включён отдельный VPN-профиль PH025.

## Вкладка «Файлы»

В полной карточке устройства можно открыть рабочую папку Sphere Agent,
выбрать или перетащить файл с компьютера, отправить его и скачать обратно.
Рабочая папка находится в app-specific хранилище Android. Доступ требуется
на уровне `device:write` к действующему устройству своей организации.
[Документация Android](https://developer.android.com/training/data-storage/app-specific).

В первой версии доступна одна папка, до 256 КиБ на файл, 16 МиБ и
100 файлов на устройство. Запись не перезаписывает существующий файл.
Браузер, API и агент проверяют размер и SHA-256. Браузер выдаёт ссылку
сохранения после проверки байтов. API отправляет команду только в
актуальную сессию агента с поддержкой протокола 1. На устройстве работает
не более одной операции. Сервер не ставит файлы в офлайн-очередь и не
хранит их на диске. После неопределённого результата записи интерфейс
требует обновить список. Полезная нагрузка не пишется в журнал API.
Имена остаются частью URL загрузки и скачивания и могут присутствовать
в журнале доступа прокси.

### Проверки

- Chromium загрузил 384 байта через HTTP 201, скачал HTTP 200 и
  сохранил байты с тем же SHA-256. Пройдены настоящий HTTP/API,
  PostgreSQL, Redis и аутентифицированный Android WebSocket.
  На этом участке использовался синтетический агент.
- На Android 14 x86_64 под обычным UID отдельный тестовый APK вызвал
  тот же Kotlin-провайдер. Проверены бинарный обмен, SHA-256,
  отсутствие перезаписи, проверка имён и отказ для ссылок. Первый опыт
  с hardlink не прошёл под UID приложения. Публикация теперь использует
  перенос в пределах одной папки под блокировкой всех штатных писателей.
- Собран dev APK 10292. В чистом Android SDK AVD агент зарегистрировался,
  но штатная защита клонов остановила подключение из-за недоступного
  процессу стабильного серийного номера VM. Сборку агента и сквозную
  проверку файлового провайдера поэтому фиксируем раздельно.
- Проверены отсутствие прав, чужая или отсутствующая цель, неподдерживаемый
  APK, размер, неверный SHA и неподтверждённый результат. Прошли 1048 Python-тестов,
  44 подтеста, 23 Jest и 19 Android-тестов. Один JVM-тест ссылок пропущен
  из-за прав Windows, тот же запрет подтверждён на Android.

### Выкладка веба и API на пилот

Веб и API собраны из `aa248297ad3eedb86fb08f111be057db70c64b03`.
Серверный образ использует пакеты действовавшего пилотного образа `99e57e04`.
Заменены только backend, frontend и review-ui. PostgreSQL, Redis, схема
`20261114_audit_cursor_idx` и параметры контейнеров сохранены. Проверены
готовность API и 16 ресурсов страницы входа через каждый из трёх шлюзов
пилота. До обновления APK Chromium показал VPN «Активен» и получил
`409 file_exchange_unsupported` при открытии вкладки «Файлы» на PH025.

### Приёмка на PH025

Адресное OTA обновило только PH025 с 10285 до `1.2.93-dev` (10293).
APK собран из `f5f27dae47c03a10d266000ed625b2fc9688374c`, SHA-256
`05196710870b9536720a41b04fa09aeb71c5a8d10a2eae9debfef3c177947bb2`
совпал с установленным пакетом. Подпись и UID приложения совпали с прежними.
Обычный канал Android OTA сохранён. Адресное разрешение установки завершилось.

В Chromium на пилоте список вернул HTTP 200, загрузка файла размером 32 КиБ
вернула HTTP 201 с квитанцией Android. После полной перезагрузки страницы
список снова вернул HTTP 200 и показал тот же файл. Скачивание вернуло HTTP 200.
Сравнение 32 768 байтов и SHA-256 сохранённого файла с исходником прошло.
SHA-256 `54c8730c239114fc66fdebab6939af13e444919bd42b6680d88f4ddec999399e`.
Независимое чтение из рабочей папки приложения на PH025 подтвердило тот же
SHA-256 и размер. Файл принадлежал UID приложения.
Ошибок выполнения страницы не было. VPN отображался активным до и после
передачи. API вернул `vpn_active=true` и свежий отчёт агента.

Замена APK перезапустила службу VPN. На время переключения Chrome был
заблокирован защитным правилом около 55 секунд. Транспорт поднялся примерно
через 50 секунд. После обновления восстановлены тот же WireGuard peer и та же
ревизия профиля Chrome, проверен `HANDSHAKE_CONFIRMED` с RX 524 и TX 14 836
байт на момент проверки. Временное правило снято, управляющая сессия вернулась.

Файловый обмен в рабочей папке принят на PH025. Общий файловый менеджер
CHAT-29 остаётся частичным. Пользовательские папки,
очередь, продолжение передачи, удаление, большие файлы и совместная нагрузка
с видео относятся к следующим этапам. Этот сценарий учитывается отдельно
от 50 пунктов продуктового реестра. Принятых пунктов по этому реестру 14.

## VPN на PH025

Создан отдельный WireGuard peer и зашифрованный профиль для Chrome на PH025.
В Android подтверждён системный запрос VPN для Sphere Agent. После применения
агент сообщил `HANDSHAKE_CONFIRMED`, счётчики приёма и передачи стали
ненулевыми. В Chromium в карточке показано «Активен», API подтвердил
свежий отчёт. Android-агент сохранил ту же управляющую сессию. Туннель
оставлен активным для Chrome. Игра, другие приложения и другие устройства
не переводились на этот профиль. Внешний IP и загрузка HTTPS-страницы
остаются непроверенными.
