# Приёмка доработок парка, групп и пакетных запусков

14 ноября 2026, Asia/Yekaterinburg. Исходное дерево `ab5236c62b0034c4587156e0bc59b42915c8861b` с рабочими изменениями. Проверен отдельный стенд с FastAPI, Next.js, PostgreSQL 15.16 и Redis 7.2. В PostgreSQL применены миграции с пустой базы. FastAPI работал под отдельной ролью без superuser и BYPASSRLS. Проверка `row_security_active('devices')` вернула `true`. Вход выполнен через штатную форму. Использованы 100 синтетических Android-устройств, тестовый оператор, четыре группы и сценарий без физических действий. Сценарии на стенде оставались в очереди или отменялись, кроме отдельного синтетического сценария pipeline с ожиданием.

## Наблюдаемость

Поиск по ID пакета связывает принятие, допущенные и отклонённые цели, волны и дочерние задания. Проверки чтения не добавляют журнал на каждый успешный запрос. Для ошибок presence добавлен счётчик `sphere_inventory_presence_failures_total` с двумя фиксированными причинами и пределом одного предупреждения о чтении за 60 секунд на процесс. На Redis стенда временно запретили `MGET`. Четыре запроса вернули неизвестное присутствие, метрика выросла на четыре, предупреждение записалось один раз. После возврата разрешения чтение восстановилось. Суточный объём журналов и доставка алертов на рабочей установке остаются приёмочными сценариями.

## Границы приёмки

- Физическое ADB-соединение остаётся без измерения. Для достоверного статуса нужно связать отчёт ADB с аутентифицированной станцией и конкретным устройством, добавить время наблюдения и проверить повторное подключение. Поле APK описывает наблюдение сервиса VPN. Маршрут трафика и handshake проверяются отдельно.
- Нагрузка реального парка, доставка управляющих команд устройствам при отмене, профиль сети и релизный APK требуют проверки на выделенных устройствах.
- Волны в этом отчёте относятся к пакетам скриптов. Пакет pipeline сохраняет версию и точные запуски. Дозированный допуск волн pipeline остаётся отдельной задачей. После неизвестного HTTP-ответа оператор сверяет историю. Идемпотентный повтор создания по клиентскому ID пока отсутствует.
- Проверены исходники с рабочими изменениями и отдельный стенд. Поставка на действующий пилот и в production не выполнялась.
