16 октября 2026. Установлены веб `ed220169` на 3015/Tuna и APK `1.2.80-dev /10280`
на четырёх доступных устройствах. API `27f3a61f` сохранён.
[Машиночитаемые результаты](AUTOMATION-INPUT80-DELIVERY.json).
[Следующий этап: полные траектории и Studio](../../design/CLIENT-STUDIO-PLATFORM.md).

## Исправление

Ранее чужой shared input participant удерживал нативный инжектор, поэтому сценарий
завершался `device_input_busy`, хотя его собственный браузер уже освободил ввод.
Теперь Android сначала закрывает допуск новых ручных сеансов, подтверждает очистку
общего touch/key инжектора и IME, затем получает эксклюзивную аренду задания.
Видео и media grants зрителей сохраняются. После завершения, отмены или deadline
аренда освобождается; браузеры получают состояние доступности и новый native READY.

Состояние доступности передаётся по существующему авторизованному DataChannel,
привязано к session/capture и монотонной ревизии. Оно не заменяет native RELEASE
и не является подтверждением исполнения команды. UNKNOWN очистки сохраняет
блокировку. Старые касания и клавиши не повторяются.

Право на вложенные действия задания передаётся через coroutine context. В том
числе исправлен блокирующий мост Lua: ввод текста не теряет это право при смене
worker-потока. Подготовка ввода входит в общий timeout; отмену можно запросить
уже во время подготовки. Параллельная активация клавиатуры не может обогнать
подтверждённое восстановление IME. В логах APK есть фазы и revision без текста
пользовательского ввода и координат.

Веб отдельно блокирует ввод на время задания, сохраняет видео, игнорирует старые
availability snapshots и корректно допускает зрителя, подключившегося во время
выполнения. Позднему подписчику передаётся только снимок состояния; старые ACK
команд не воспроизводятся.

- Подписанный APK: lint/assemble dev и enterprise; по 1231 unit test, 0 ошибок,

  это не заявление, что все исторические workflow уже перенесены.
- Заменён только UI-контейнер; 45 остальных сохранены. Docker archives не создавались.
- PH011, PH010, PH025, PH030: completed OTA receipt и фактический installed package SHA
  совпали с `7b8f8ec8ffab3804fcf00702834fb175fe702ff40f07e6e0f5bc4ea6df9f511b`.
  PH030 уже был обновлён пользователем; повторный grant ему не отправлялся.
  Семнадцать offline устройств не обновлены; обычный Android-канал сохранён.

В настоящем Chrome на PH011 выполнены пять конечных случаев:

1. Два управляющих клиента, запуск Start→Sleep8s→Home→End через Studio на3015.
2. Та же проверка через Tuna.
3. Отмена во время выполнения sleep: terminal cancelled, затем ручной READY.
4. Третий зритель подключён во время Sleep20s; после задания получил ручной READY.
5. Во втором клиенте удерживался подтверждённый DOWN; задание создано через API,
   Android освободил удержание и завершил сценарий без предварительного handoff UI.

Во всех случаях direct video сохранилось, счётчики кадров выросли, исходные media
peers не пересоздавались, ручное управление вернулось автоматически. После этого
новое нажатие Home получило native applied. Ошибок страниц не было. Скриншоты
состояний задания и возврата ввода просмотрены. Пять временных сценариев архивированы,
версии и задания оставлены для аудита; собственные контексты и браузер закрыты.

## Что ещё не готово

**APK80 не добавляет полную запись траекторий.** Сложный или медленный жест пока
может быть явно пропущен старым форматом. Следующий action должен хранить один
непрерывный жест одной нодой: DOWN, точки/времена MOVE, удержания, развороты и UP.
Нужны общий контракт, серверная валидация, Android-исполнитель и реальная приёмка.
XPath/цвет/crop 30×30 или50×50, переименование/группировка нод также не объявлены
реализованными этой поставкой.

Отмена проверена внутри восьмисекундного sleep; текущий executor завершает её на
следующем контрольном шаге. Мгновенный cancel/SLA не принят. Проверка десяти
участников — unit test, а реальный браузерный объём здесь два/три клиента, не20.
Первый ICE retry PH025, физические hotspot/VPN сценарии, offline continuity,
SDK clock regression и длительная production-нагрузка остаются открытыми.

Account sync, AI authoring, полный файловый менеджер, VPN providers, плагины и
лёгкие ≤1FPS previews остаются в общем плане. Модель не скачивалась и не запускалась.
