# Проход к метке: конечный визуальный контроллер

17 октября2026, PH011, TYUMEN. Пользователь после завершения подтвердил: «добежала».
[Машиночитаемая квитанция](MOTOR-WAYPOINT-SERVO.json).

По прямым кадрам APK работал отдельный прототип: распознавание красного3-D pin по цвету/форме,
затем коррекция виртуального стика относительно положения pin на экране. Это deterministic
visual servo, без NitroGen, Pixel2Play и GPU inference. Целью был один пользовательский waypoint.

| Проверка | Наблюдение |
| --- | --- |
| Расстояния, прочитанные по кадрам | 241→110→46→25м |
| Завершение | Метка и маршрут на миникарте исчезли; пользователь подтвердил прибытие |
| Длительность monitor | 56.538с при верхнем бюджете180с |
| Наблюдения/коррекции, включая setup | 296 /5.126Гц по последовательности |
| Native ввод | 36/36 APPLIED:1 DOWN,35 MOVE |
| Освобождение | Подтверждён native CLOSED; удержаний после теста нет |
| Receiver→visual decision | p50 33.454мс, max98.450мс |
| Серверные media bytes клиенту | 0 при bootstrap и после direct handover |

Персонаж непрерывно бежал по направлению к pin. Неизменное направление не требовало повторных
DOWN/MOVE каждые200мс: состояние сохранялось, наблюдения продолжались. При первом отсутствии pin
стик переведён в центр, после пяти отсутствующих наблюдений опыт завершён. Исчезновение pin
само по себе не является универсальным arrival detector; здесь есть отдельное подтверждение человека.
Кадр с точным0м не записан. Исходный `goalReachedConfirmed=false` отражает момент до подтверждения
пользователя и сохранён неизменным; новая квитанция содержит post-run подтверждение отдельно.

`transport.success=false` тоже сохранён: текущий контракт транспортного теста требует полной
заданной длительности180с. Прототип остановился раньше по `visual_target_lost`; failure=null,
36/36 APPLIED и CLOSED подтверждены отдельно. Нельзя задним числом подменять этот флаг на true.

Сквозная capture→action задержка, повторяемость маршрутов, обход препятствий, автомобиль,
камера/multi-touch, отдельная GPU/LAN и нагрузка не приняты. Прототип и volatile кадры хранятся в
`.local-pilot/motor-amd-20261017/waypoint-cv-v1*`, SHA исходника и evidence сохранены в квитанции.
UI/API15ce и APK82 не менялись. Этот успех не означает приёмку goal following нейросети:
[предыдущие learned опыты и ограничения](MOTOR-STICK-CONTACT-LIVE.md).
