# Подготовка ориентиров: память и неполная карта

Дата проверки: 29 октября 2026, Asia/Yekaterinburg.

## Установленная причина

Сообщение пользователя объединяло два разных события. Предварительная
проверка новой подготовки требовала 12 ГиБ свободной ОЗУ. В сохранённой
квитанции отказа свободно 11,68 ГиБ; новая попытка не создавалась.
Одновременно интерфейс показывал результат предыдущего экспорта:
`route_map_has_unobserved_sections`.

Для `fuflo228` основной результат содержит 54 камеры и 1236 runtime-ориентиров.
Он покрывает 0–28,258 с из 33,258 с записи. Между 10,807 и 12,341 с нет
восстановленного ракурса; последние 5 с не покрыты. Целостность видео и
полнота зарегистрированных камер — разные свойства. Повторное извлечение
дескрипторов из тех же поз не добавит пропущенные камеры.

## Изменения

- Ограниченный CPU-экспорт получил отдельный бюджет: 4 ГиБ запаса для хоста,
  1,5 ГиБ на runtime, три размера сжатого исходника и две таблицы признаков
  до 256 × 2048 × 128 float32. Порог округляется вверх по 0,25 ГиБ, минимум
  6 ГиБ; неизвестный источник сохраняет консервативные 12 ГиБ.
- Для этой записи порог равен 6,25 ГиБ. GPU-модель для экспорта не загружается;
  OpenCV использует два потока. Live-локализация имеет отдельный порог 6 ГиБ.
  Остальные пороги сборок/реконструкции не изменены. Проверки commit <85%,
  диска и состояния тома сохранены.
- API возвращает измеренное покрытие также для отклонённой карты.
  UI показывает время окончания карты, конец исходника и реальные разрывы.
  Отказ новой предварительной проверки отделён от старого результата.
- Повторный экспорт известной карты с пропущенными временными участками
  не создаёт процесс и не расходует попытку; интерфейс ведёт к восстановлению
  камер. Это не автоматическое исправление поз и не допуск управления.
- После обнаружения отсутствующего listener локальный обработчик восстановлен
  на 3342. Health вернул 200; запрос управления без capability — 403.

## Проверка на настоящих данных

Отдельный диагностический экспорт существующей модели на 123 камеры выполнен
в CPU-окружении live-сервиса (OpenCV 4.13, одинаковый pipeline SHA). Он не
изменял основную карту, исходное видео, геометрию или управление Android.

| Показатель | Результат |
|---|---:|
| Время, включая проверки ресурсов | 106,14 с |
| Пиковый working set процесса | 366,9 МиБ |
| Пиковый commit процесса | 856,6 МиБ |
| Минимальная свободная память хоста во время опыта | 8,58 ГиБ |
| Камеры / пересобранные ориентиры | 123 / 3740 |
| Неизменность хешей источника и модели | подтверждена |

Это измерение одного экспорта, а не гарантия такого потребления для любого
видео. Бюджет учитывает максимальный разрешённый размер подкарты и исходника.
Все временные интервалы модели из 123 камер представлены, однако две
окрестности не достигли порога 24 ориентиров (22 и 13). Дополнительно
сохраняются сомнительные изменения поз в хвосте. Диагностический результат
не принят для автономного движения и не подменяет основную карту.

## Воспроизводимость и границы

Веб собран локально с одним worker и Node heap 1024 МиБ. Хеш исходников
до/после сборки совпал:
`49cc2238b1347db65239f09ac7d7d0e5e6ed7ffb1e38fceb50cc88821249a436`.
424 файла пакета проверены по хешам; изолированная проверка подтвердила
две страницы, 31 asset, новый текст ошибок и неизменный recorder worker.

На 3015 установлен `sphere-route-local:route-resource-fix-20261029-v1`, image
`sha256:e50fece2c5b73969d3258678e691f3ac35ccbc18f15eab9325910a761444a8d5`.
Контейнер healthy, остальные контейнеры сохранены. Возвратная версия —
`sphere-route-local:walk-pilot-20261028-v2`; квитанция установки находится в
`.local-pilot/route-resource-fix-image-v1/install-receipt.json`.

Проверки: 18 unittest workspace, 77 pytest границ сервиса/ресурсов/квитанций,
33 frontend-теста, TypeScript и production build прошли. В pytest без
автозагрузки плагинов есть предупреждение о неиспользуемом `asyncio_mode`;
сборка содержит прежние lint-предупреждения. Визуальная приёмка в настоящем
профиле браузера не завершена: инструмент Windows Computer Use остановил
навигацию с сообщением `browser URL policy enforcement is not yet supported
for the current Windows browser`. Обход ограничения не выполнялся.

Локальные квитанции: `.local-pilot/route-resource-benchmark-20261029-v1/`,
`.local-pilot/route-service-restore-20261029-v2/`. Они не публикуют capability,
секреты или исходную видеозапись. Публичная сводка: соседний
`route-resource-evidence.json`.

Регрессии покрывают допуск короткого экспорта при 11 ГиБ, сохранение
ограничений commit, отказ без нового intent, чтение существующего intent без
повторного запуска, сохранение временного покрытия и отсутствие бессмысленного
POST из интерфейса для известной неполной модели.
Статус `ready` без квитанции отклоняется; старая квитанция без сведений о
покрытии не вызывает внутреннюю ошибку сервиса при новой подготовке.

Разделение камер/разреженной карты и плотного рендера соответствует
[официальному описанию COLMAP](https://github.com/colmap/colmap/blob/main/doc/tutorial.rst).
Параметр `nfeatures` ограничивает число сохраняемых лучших SIFT-признаков,
как описано в [справочнике OpenCV](https://docs.opencv.org/4.12.0/d7/d60/classcv_1_1SIFT.html).
Эти документы не задают наш порог памяти: он рассчитан по локальным лимитам
и проверен указанным измерением.
