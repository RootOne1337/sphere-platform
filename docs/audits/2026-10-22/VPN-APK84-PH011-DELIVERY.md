# APK84: адресная установка PH011

22 октября 2026, время Екатеринбурга. Эта квитанция подтверждает установку
одного APK; подключение прикладного VPN принимается отдельно.

- На `auto-ph-011` установлен `1.2.84-dev / 10284` через штатный адресный OTA.
  Завершение OTA подтверждено после перезапуска процесса. Независимый SHA-256
  установленного пакета совпадает с подписанным артефактом.
- Исходная ревизия APK — `7f06701ed6f1a0fd66a0d7d5f50234160e5324cd`.
  Подпись принадлежит существующему pilot, discovery identity сохранена.
- [Android CI](https://github.com/RootOne1337/sphere-platform/actions/runs/39668905286)
  завершился успешно. Android tree и исходник native builder совпадают с локальным
  подписанным кандидатом; CI использовал отдельную тестовую подпись. Установленный
  APK не объявляется собранным GitHub, его source SHA не заменён на CI SHA.
- В каждом dev/enterprise canary suite — 1275 тестов, без failures/errors.
  Hosted runner пропустил один тест, локальная проверка — три. Эти числа не
  объединяются в заявление о прохождении каждого теста на каждой платформе.
- В APK включены три ABI hardened WG/AWG native runtime. Конечные root-TUN опыты
  прошлой поставки остаются самостоятельными доказательствами; они не заменяют
  проверку `VpnService`, consent, revoke, sleep/boot и смены сети основного APK.
- PH030 был offline перед выдачей разрешения на обновление. Для него не выдан
  grant APK84 и не отправлена команда установки. Fleet rollout не выполнялся.
- Общий Android OTA-канал сохранён, очистки данных и `adb install` не применялись.
