# Script Studio: редактирование связей и готовые клавиши

Дата: **6 октября 2026**, UTC. Базовый source: `bc9f4bb`.
Статус: **исправление в исходниках; установка в веб ещё не выполнена**.
Установленный UI на 3015: `1c26ffc7`; API: `eb7a7c26`.

## Подтверждённая проблема

Временный новый документ `/scripts/builder`, Start → End, не публиковался.
В работающем браузере линия выделяется, Delete удаляет её, число связей
становится нулём; Undo восстанавливает `on_success` в JSON. Таким образом,
механизм удаления уже работал, но отсутствовали явная кнопка и редактор связи.
Для оператора это выглядело как невозможность разорвать соединение.

Перетаскивание конца существующей связи также не было подключено: React Flow
требует `onReconnect`. Это отдельный функциональный пробел, а не смена движка.
[Официальный контракт React Flow](https://reactflow.dev/examples/edges/reconnect-edge).

## Изменение

- Нажатие на линию открывает редактор с полями **Откуда / Когда / Куда**.
- **Разорвать связь** удаляет только переход; оба шага остаются.
- Конец линии можно перенести через штатный `onReconnect` React Flow.
- Область попадания в линию расширена до 28 px, радиус переноса конца — 16 px;
  выбранный маршрут выделяется более толстой линией.
- В лаборатории устройства редактор появляется на графе, не закрывая поток
  и запись. В обычном режиме он занимает существующую правую панель параметров.
- Без права записи, во время загрузки/сохранения или при неприменённых
  параметрах шага изменение переходов блокируется.
- Успех, ошибка, true/false преобразуются обратно в DAG 1.0 без изменения
  чужих маршрутов. Один выход не может вести сразу к двум целям.
- Сохраняется legacy `condition.on_success`, если он уже присутствует в DAG.
- Событие переноса для уже удалённой линии отклоняется. Нет неявного добавления
  удалённой связи или перезаписи другой ветки.
- Добавлены шесть настроенных `key_event`: Домой, Назад, Недавние, Меню,
  Enter, Backspace. Нажатие этих кнопок библиотеки добавляет шаг, не управляет
  Android и не отправляет shell-команду.

## Границы

Временно разорванный граф остаётся редактируемым. Если он оставляет недостижимые
шаги или неполное условие, публикация отклоняется прежней проверкой структуры.
Undo/Redo по-прежнему восстанавливает документ в JSON; переход в Граф импортирует
восстановленный исходник. Раскладка и положение узлов не входят в wire DAG.

Это не grouping/subgraphs, запуск пайплайна как узла, покадровый replay или
расширенная запись XPath/PNG/цвета. Они учитываются отдельным планом.
Удаление или перенос связи не выполняет сценарий на Android.

## Установка и приёмка

Тяжёлая сборка и deployment не выполняются на C:, пока Windows сообщает
`Warning / Full Repair Needed`: [host incident](HOST-FILESYSTEM-INCIDENT.md).
Этот документ не подтверждает завершение запланированного ремонта или reboot.

После восстановления хоста: собрать проверенную UI ревизию, установить через
существующий preview launcher и повторить в браузере:

1. Линейная и условная связь: выбор мышью → смена цели → экспорт JSON.
2. Условие: менять Да, Нет и Ошибка отдельно, без потери других ветвей.
3. Занятый выход: видимый отказ, исходник не изменён.
4. Разрыв → недостижимый шаг: сохранение не выполняется, Undo восстанавливает маршрут.
5. Перенос конца линии мышью; отмена незавершённого переноса сохраняет старый маршрут.
6. Read-only и неприменённые параметры блокируют кнопки и перенос линии.
7. Лаборатория с живым Android остаётся открытой при изменении связи.
8. Dark/light, 1280 px и узкий viewport: поля и кнопка не перекрывают видео.

Общий реестр аудита остаётся **9 accepted / 41 open**. Этот source fix не закрывает

Авторство/лицензия React Flow сохраняются; чужой коммерческий шаблон не копировался.
