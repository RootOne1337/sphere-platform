# APK76: очередь физических клавиш

Подготовка исходников, а не приёмка установленного APK76. Веб и API04cf101
обслуживают3015 и Tuna. APK75 установлен только на PH011; его массовая рассылка
удержана. PH030 остаётся на73, остальные доступные устройства — на72.

На PH011 / APK75 фактическая проверка Android подтвердила Unicode, удаление целого
emoji и ввод в fullscreen. После завершения прежний IME восстановился. Проверка
Ctrl+A отклонена: четыре события были отправлены по direct data channel без
серверного ввода, подтверждения клавиш не пришли и управление пересоздалось.

Причина воспроизводится синхронно в SharedInputMailbox: старый pointer budget
разрешает три обычных события и резервирует четвёртый слот для UP/CANCEL. Четыре
keyboard edges считались обычными событиями. OVERFLOW очищал очередь и ставил
cleanup; поэтому обработчик не мог подтвердить отброшенные клавиши.

APK76 выделяет32 ограниченных keyboard entries каждому из10 авторизованных
участников. Последний слот сохраняется для KEY_UP/RESET/FINISH. Четыре pointer
entries и их terminal reserve остаются отдельными; MOVE и heartbeat продолжают
coalescing по прежним правилам. Глобальный порядок прихода сохранён. Одновременно
может храниться не более360 entries; текст ограничен1024 UTF-16 units в каждой
команде. Фиксированный drain pass остаётся40 операций, без увеличения времени
между проверками expiry и native heartbeat. Это не разрешение на бесконечный ввод
или скрытый повтор переполненных команд.

Отказы очереди теперь увеличивают существующий INPUT_REJECTED diagnostic counter
и пишут только фиксированный admission code, без owner, клавиш, координат и текста.
Владение IME публикуется между worker/actor через volatile. Новые тесты покрывают
быстрый modifier chord с heartbeat без drain,32-entry предел и key release,
совместную очередь клавиатуры и pointer cleanup;51 сфокусированный тест прошёл.

Нужны полный signed build, повторная фактическая проверка Unicode/selection/
composition/game keys/fullscreen, несколько клиентов и reconnect. APK76 пока не
является1.3.0/stable. Server full keyboard,20+, телефон/hotspot/WAN/TURN, работа
без broker, audio и полный перенос hosted CI остаются открытыми.
