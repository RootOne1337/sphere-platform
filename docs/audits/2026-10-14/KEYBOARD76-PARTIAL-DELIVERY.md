# Клавиатура76 и текущая граница совместного сеанса

Срез выполнен14октября UTC /15октября местного времени. Это частичная конечная
проверка, не production-приёмка. [Неизменяемый протокол](KEYBOARD76-PARTIAL-OBSERVATION.json)
связывает текущие контейнеры, APK, фактические проверки и сохранённый отрицательный результат.

UI `b182a0c8` / API `04cf1015` обслуживают3015 и Tuna; файлы login совпадают,
HTTP-схема соответствует `docs/openapi.json`:149 путей/188 операций.
APK `1.2.76-dev /10276`, source `b3e2b96`, подписан тем же стендовым ключом.
PH011 подтвердил установленный SHA и completed OTA. PH030 сообщает76 с точным
completed OTA, но свежий хеш установленного пакета удержан активным вводом.
13 доступных устройств остаются72; шесть офлайн без нового grant.
Это canary, не ordinary Android channel и не stable1.3.

Два независимых локальных клиента прошли12 раундов реальной mouse/touch,
все четыре системные кнопки и управление после закрытия одного участника.
НаPH011 черезTuna прошёл fullscreen physical keyboard:Unicode,Backspace,
Ctrl+A,композиция и игровые key edges. Текст проверен непосредственно в
выделенном Android-редакторе; прежний IME восстановился. Пользовательские
поля не считывались и действия вPH030/PH010 не вводились.

Новый прогон десяти клиентов черезTuna не принят. Все10 login дали200, но
часть ранее готовых peer потеряла READY при открытии остальных; девятый
клиент оказался на/login до кнопки потока. Ошибок pageerror не было,
системные команды этого прогона не начались; все10 тестовых контекстов закрыты.
Есть1013 `direct_video_retry`, последующие низкие H264 receiver profiles и
1006 signaling closures. Это наблюдения; единственная первопричина ещё не доказана.
Первый отрицательный login-navigation прогон тоже сохранён. Более ранние
десять клиентов наUI4525/том жеAPK76 и три RTC-rejoin прошли, но не заменяют
новую проверку установленного стека. Массовая OTA76 пока удержана.

Source `adc598e3` подготовил два исправления. Transient refresh failure
(timeout/408/429/5xx) больше не удаляет текущую identity и credentials;
сам запрос завершается ошибкой без скрытого повтора. Подтверждённый auth
rejection, malformed tokens и смена identity остаются terminal.
Signaling пишет только фиксированный reason code и этап остановки, без
токенов, SDP, адресов и содержимого команды. Эти изменения на момент среза
ещё не установлены. До auth-фикса пять новых регрессий воспроизвели logout;
после прошли2429 frontend tests/167 suites,tsc и101 targeted routing/diagnostic
tests без skips; локальные статусы подтверждены наGitHub. Полный backend CI
наadc остановился на устаревшем Markdown inventory; это не успешный полный run.

Последний canary APK скачан целиком с обоих адресов:57,819,657bytes,
одинаковыйSHA;829мс локально/59625мс черезTuna в данном замере. Это время
скачивания, не задержка видео и не гарантированная скорость для всех клиентов.
Полный перенос CI наПК не завершён; зарегистрированных self-hosted runners0.
Репозиторий сейчас public, стандартные hosted runners бесплатны по текущим
[правилам GitHub](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
Это не утверждение об отсутствии любых платежей по аккаунту или другим продуктам.

Открыты: новая десятиклиентная приёмка/rollout, реальный телефон/hotspot,
