# Подготовленный комплект 74: восстановление управления и клавиатура

Это описание исходников, а не доказательство установки. Полная доставка и проверка
на Android ещё не приняты. APK73 установлен только на PH011 и PH030; UI216694c4 /
APIc4a564b8 обслуживают3015 и Tuna. Последняя полностью принятая рассылка — APK72.

На APK73 прошли два независимых клиента через оба адреса: по12 раундов mouse/touch,
системные кнопки и сохранение управления после закрытия одного клиента. Три фактических
закрытия RTC восстановили прямой канал и native Home. Проверка десяти клиентов
отклонена: четвёртый получил direct video после неудачного fallback, но control остался
closed. Поэтому массовая рассылка73 удержана.

Комплект74 исправляет переход к готовому direct endpoint после точного RELEASE старого
fallback, независимо от порядка событий. Отказ до запуска native process при занятом
инжекторе теперь классифицируется как known startup refusal. Отказ STARTUP отправляет
завершение нового участника, а participant удаляется до публикации CLOSED: быстрый
повторный OPEN не должен столкнуться со старой записью. UNKNOWN cleanup не сбрасывается
таймером или новой вкладкой. Предыдущие действия не повторяются.

Клавиатура включается явно в выбранном стриме и остаётся в том же native control actor:
keydown/keyup и modifiers для игр; commit/composition/delete для редактируемых полей.
Android IME временно включается через root; последнее отключение восстанавливает
предыдущий IME, сохраняя выбор локального пользователя. Службу может привязать только
Android с BIND_INPUT_METHOD. У неё нет публичного receiver для текста.

Текст не передаётся shell-команде, не хранится в метриках и не включается в исключения.
Payload ограничен1024 UTF-16 units /8192 wire bytes, корректной Unicode-последовательностью
и точными полями. Native keys ограничены16 удерживаемыми клавишами. Клавиши освобождаются
на blur/hidden/закрытии или передаче управления другому участнику. Завершённое нажатие
означает принятие native API; это не доказательство обработки приложением или вывода кадра.
Ошибки no_editor/stale_editor/unknown выдаются отдельно, без скрытого повторения текста.

Для живой проверки добавлен явно запускаемый root-only debug fixture с двумя настоящими
EditText и площадкой hardware keys. Он отсутствует в обычных APK. Нужны проверки Unicode,
выделения/удаления, composition, modifiers, fullscreen, смены участника и восстановления.
Клавиатура пока согласуется только для APK≥10274 и shared direct control. Полная клавиатура
на серверном fallback, несколько fallback-клиентов и недостающие WAN/mobile границы
остаются открытыми до отдельной реализации/проверки.

Счётчики клавиатуры содержат только количество, фиксированный outcome и monotonic age.
Добавлено диагностическое различие control channel setup и media readiness. Очистка
reviewed archives теперь сохраняет новые скачанные кандидаты до Docker load; установка
API больше не должна удалять ожидающий установки веб-образ.

Реальный телефон/hotspot,20+ клиентов, длительная стабильность, отсутствие broker,
адаптивные native ACK deadlines, optional audio и полный перенос hosted CI не приняты.
Ни близкое физическое расстояние, ни ICE connected отдельно не доказывают рабочий ввод.

Источники: [Android InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection)
и [Android IME](https://developer.android.com/develop/ui/views/touch-and-input/creating-input-method).
Предыдущая полная доставка: [APK72](DIRECT-SYSTEM-INPUT72-DELIVERY.md).
