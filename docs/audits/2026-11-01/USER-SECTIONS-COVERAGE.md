# Сверка пользовательских разделов: доступ, действия и границы

Срез **1 ноября 2026**: исходная ревизия `555b620a`, рабочее дерево во время
документационной сверки. Перечислены основные группы действий и найденные tests,
а не каждый DOM-элемент и не приёмка работающей установки. Реальные аккаунты,
сети, webhook-получатели и устройства не изменялись. Права ниже — требования
конкретных маршрутов backend; видимость элемента сама по себе не доказывает
доступ или успешное выполнение операции.
