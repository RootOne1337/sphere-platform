## Источники и пределы данных

| Раздел | Источник | Предел и поведение |
| --- | --- | --- |
| Обзор | `GET /devices/{id}` | Одна выбранная запись; 15 секунд. CPU/RAM/заряд/экран/версия только при сообщённых значениях |
| Задачи | `GET /tasks?device_id=...&per_page=6&sort_by=created_at&sort_dir=desc` | Последние 6 задач и API total этого устройства; ссылка на фактический `/tasks/{id}` |
| События | `GET /device-events?device_id=...&per_page=6&sort_by=occurred_at&sort_dir=desc` | Последние 6 событий; task_id ведёт на результат задачи. Не общий журнал всех стадий |
| Видео | `GET /devices/{id}/stream-diagnostics` | Состояние freshness API и локальные счётчики APK; принятие очередью не доказывает доставку/картинку |
| Логи APK | `GET /logs/{id}?lines=100` | Только сохранённые на сервере строки, доступны при офлайн Android; ручное обновление, без auto poll |
| Видеопоток | `/ws/stream/{id}` через существующую авторизацию | Отдельное подключение по явному действию; первый кадр, stale, ошибки/счётчики существующего decoder |
| PNG | Canvas браузера | Кнопка активна после успешного render и до stale; PNG не равен новому независимому Android screenshot |
| Shell/Logcat | Существующие `POST /devices/{id}/shell`, `/logcat` | Результат валидируется; закрытие панели отменяет ожидание и не отправляет следующие команды. Отмена HTTP не доказывает отмену уже полученной команды. Shell-скрипт — последовательные shell-команды, не автономный DAG mission |
| Reboot | `POST /devices/{id}/reboot` | Подтверждение, один запрос, локальный синхронный lock; timeout/неожиданный ответ не объявляются успехом и не повторяются автоматически |

Разделы истории/диагностики загружаются только при открытии соответствующей
вкладки. При ошибке новый ноль не подставляется; сохранённый ответ явно отмечается
как потенциально устаревший. Ответы с чужим `device_id` отклоняются. Счётчики без
данных выводятся как «Не сообщено»; `0` остаётся настоящим нулём.

Полная страница и боковой инспектор используют один компонент. Переименование,
назначение групп/локаций и удаление остаются в реестре; карточка содержит ссылку
на эти действия. Нерабочая PC Agent кнопка подключения ADB с полной страницы
удалена: ADB показывается как дополнительный сообщённый канал, а не обязательная
зависимость Android-first установки.

## Оставшиеся работы

Единый incident timeline, pipeline/OTA receipts, reconnect history, retention и
метрики end-to-end latency остаются в общем аудите. Нет заявления о готовности
500–1000 устройств. Независимое remote screenshot API без активного браузерного
потока требует Android command/receipt/upload контракта; старый PC Agent путь
такого доказательства не предоставляет.
