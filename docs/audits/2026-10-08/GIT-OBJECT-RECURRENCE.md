# Повторный повреждённый Git blob: точечное восстановление

8 октября 2026, Asia/Yekaterinburg. При проверке изменения continuous input
`git diff` не смог распаковать объект
`ba6d998cd25d9e5592fdbc619001bc62e8022b99`: `incorrect header check`.
Index связывает его с `frontend/src/features/stream/continuousPointer.ts`.
Это повторение ранее наблюдавшейся неисправности локальных Git objects;
само наблюдение не устанавливает причину повреждения или заполнения диска.

Перед восстановлением сохранены все 13 изменённых файлов этого этапа и исходные
6048 байт повреждённого compressed object в приватном каталоге `.local-pilot`.
Файлы рабочей копии проверены SHA-256 до и после: содержимое не менялось.
Чужие изменения и остальные untracked файлы не включались в операцию.

Из authenticated GitHub Git Blob API получен именно этот объект, не новая
версия исходника. Проверены returned SHA, encoding base64 и Git canonical
`SHA1("blob " + length + NUL + data)`: результат равен указанному object ID.
Проверенное содержимое размером 18976 байт сжато zlib и повторно распаковано
для проверки. Восстановлен только соответствующий loose object. Атрибут
read-only этого конкретного файла снят для замены; ветка, index и рабочая
копия не откатывались. `git diff --check`, точечный commit и push затем прошли.

Причина повторения остаётся открытой. Эта операция не является доказательством
исправности SSD/NTFS, не решает продолжающийся расход места и не меняет VSS,
план загрузки или настройки Windows. Повреждённые байты сохранены для дальнейшей
атрибуции. Проверка полноты всех Git objects этим точечным ремонтом не заявляется.
