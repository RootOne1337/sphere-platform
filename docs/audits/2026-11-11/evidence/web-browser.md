# Загрузка страниц в изолированном браузере

11 ноября 2026 года. Рабочие исходники frontend от `94cf7c3a2a50bbc8197737f5cf666e0e2c8ddec3` скопированы во временный каталог с текущими локальными изменениями. Next.js `15.5.26` запускался в режиме `dev` на `127.0.0.1:49498`. Playwright CLI открыл отдельный headless-сеанс Microsoft Edge `157.0.4341.46`.

API подменялся в браузере. Для защищённых страниц использовались синтетический пользователь и набор разрешений, списки без записей и отдельная карточка отключённого устройства. `/login` открыт без авторизации. HTTP за пределами loopback и WebSocket приложения блокировались, операциям записи фикстура отвечала `405`. Backend, review UI и пилотная установка в проверке не участвовали.

**Результат** — все 29 маршрутов открылись в ожидаемом состоянии. Финальные документы дали HTTP `200`, указанный элемент страницы был видим, до его проверки событие `pageerror` не наблюдалось. В первой попытке потребовалось уточнить две формы тестовых API-ответов и два селектора браузерной проверки. Итоговая таблица относится к повторному полному проходу после этих изменений фикстуры. Проверка подтверждает открытие страницы и появление её контрольного элемента. Для действий внутри страниц, загрузки данных реального API, WebRTC, переключения вкладок, мобильной компоновки и сочетаний ролей нужны отдельные сценарии. Пять серверных обработчиков Next.js входят в статическую матрицу, browser smoke их контрактов не выполнял.

Тестовый браузер и сервер остановлены.

Для повторения поднимите Next.js на указанном loopback-порту из временной копии `frontend` с установленными зависимостями. Перед стартом задайте `NEXT_PUBLIC_API_URL=/api/v1`, `NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:49499` и `NEXT_PUBLIC_WS_URL=ws://127.0.0.1:49498`. Порт `49499` в этом прогоне не обслуживался. В отдельной командной сессии используйте Playwright CLI и абсолютный путь к `web-browser-run.js`.

```powershell
npx.cmd --offline --package @playwright/cli playwright-cli -s=sphere-web-audit-20261111 open about:blank --browser=msedge
npx.cmd --offline --package @playwright/cli playwright-cli -s=sphere-web-audit-20261111 run-code --filename <absolute-path-to-web-browser-run.js> --raw
npx.cmd --offline --package @playwright/cli playwright-cli -s=sphere-web-audit-20261111 close
```
