## Docker относится ко всему компьютеру

До удаления: 252 образа, 46 контейнеров (14 работающих), 75 volumes,
1 005 записей BuildKit. Docker сообщил 187,1 GB образов и 90,19 GB кэша.
У этих категорий есть общие данные; их нельзя складывать как независимые файлы.
См. [официальное определение SHARED/UNIQUE/SIZE](https://docs.docker.com/reference/cli/docker/system/df/).

В инвентаре обнаружены не только образы Sphere: есть серии MiniFactory,
SphereADB, базовые Go/Node, Ruflo, служебные сервисы. Например, три группы
`sphere-mini-factory-race`, `mini-factory-race-check`, `mini-factory-race`
содержат 27 образов. Удаление образов чужих для текущей задачи проектов
и общий Docker prune не выполнялись.

Файл `AppData/Local/Docker/wsl/disk/docker_data.vhdx`:
249 452 036 096 логических и выделенных байт (**232,32 ГиБ**).
Это отдельный файл от `.local-pilot`; оба занимают C:.
Текущее использование ext4 внутри виртуального диска также измерено отдельно.
Размер VHDX не следует объявлять освобождённым по ответу `docker image rm`.
Во время этой операции Docker не останавливался, VHDX не сжимался.
