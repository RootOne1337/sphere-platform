# Изолированная браузерная проверка диагностики

13 ноября 2026, Chromium `157.0.8103.51`, Next.js `15.5.26`, копия frontend рабочего среза `b8273839`. Playwright перехватывал HTTP API и WebSocket приложения; разрешены только loopback Next и его HMR. Выдавалась синтетическая сессия и ответы ниже. Проверка UI не использовала рабочий API, Android, Redis или адрес получателя вебхука. На первом холодном открытии сборка Next не успела выдать chunk; сервер прогрели обращениями к проверяемым маршрутам, итоговый прогон завершился.

| Маршрут | Ввод и действие | Наблюдение |
| --- | --- | --- |
| `/events` · 1440×900 | Ввод `missing-fixture`, затем «Обновить» | Заголовок `0 записей` при карточке «Всего» `41`. После клика `GET /device-events?page=1&per_page=50&search=missing-fixture&sort_by=occurred_at&sort_dir=desc`; отдельного запроса stats в этом действии не наблюдалось. |
| `/event-triggers` · 390×844 | Каталог `/pipelines` отвечает `503`. Открыть «Создать триггер» и список сценариев | Видно «Нет доступных сценариев». `Event Triggers` имеет `font-size:20px`, JetBrains Mono/fallback и `text-transform:uppercase`; у `События устройств` `font-size:24px`, Inter/fallback и `text-transform:none` на 1440 px. Семейства и transform подтверждаются также по исходникам. |
| `/webhooks` · 390×844 | Запись `is_active=true`, `failure_count=7`, `last_triggered_at=null` | «Активен», дата создания, событие и «Отключить». Статус доставки и 7 отказов отсутствуют в видимом тексте списка. |
| `/logs` · 1440×900 | Открыть по `device_id`, затем выбрать «Ошибки». Файловая и `threadtime` строки с уровнем `E` | До фильтрации видны `RECENT SPHERE CRASH` и `No persisted uncaught crash record`. После фильтрации остаётся файловая ошибка, строка `threadtime` скрыта. |
| `/audit` · 1440×900 | 101 запись. На первой странице 100 успешных; на второй одна ошибка | «Всего 101» на обеих страницах; карточки меняются со `100/0` на `0/1` и подписаны «На загруженной странице». Это корректное различение охвата для текущего дизайна, предложения о серверных агрегатах относятся к развитию. |

В дополнительном сравнении при одинаковых 1440×900 и `light-corporate` оба заголовка сохранили описанные различия. У шапки таблицы триггеров фон `rgba(21,21,21,0.9)`, текст `rgb(90,104,124)`. На белой подложке расчётный контраст составляет около 2,46:1. На снимке также заметна тёмная подложка поля поиска. [События](events-light.png) · [Триггеры](triggers-light.png).

Воспроизведение: запустить копию frontend на `127.0.0.1:49513` с установленными зависимостями и upstream dev-proxy на loopback-заглушке, создать каталог `output/playwright/`, открыть новый Playwright CLI сеанс на `about:blank` и выполнить `playwright-cli -s=<session> run-code --filename docs/audits/2026-11-13/evidence/operator-browser.js` из корня репозитория. Файл содержит входные данные, клики и запись наблюдений. [Сценарий](operator-browser.js) · [Карточки](../OPERATOR-WORKFLOWS.md).
