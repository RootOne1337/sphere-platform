# Доказательства по инфраструктурным журналам

13 ноября 2026, Docker Compose 5.1.0. Работающие локальные сервисы проверены чтением. Содержимое строк, идентификаторы устройств и значения окружения не сохранены. Сумма байтов дневных файлов отражает их размер на момент проверки. Для Docker `--tail 1000` задаёт предел выборки, даже если запрошено окно `--since 24h`.
