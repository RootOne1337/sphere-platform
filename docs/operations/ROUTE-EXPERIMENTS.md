# Реестр эталона и экспериментов маршрутов

Актуальный указатель на результаты `skuter1`, связанные проверки локализации
и сравнительную запись `skuter2`. Срез: **4 ноября 2026 года**. Подробные
квитанции остаются в датированных отчётах; их исторические результаты не
объявляются новой проверкой установленного runtime.

**Приоритет — распознавание и сопровождение по выбранному пользователем
эталону skuter1 при смене дня и ночи.** Новые реконструкции skuter2 нужны для
сравнения метода; они не заменяют этот эталон. Геометрия, выбор просмотра,
runtime-карта, подтверждённая локализация текущего кадра и управление имеют
отдельные состояния допуска.

Рабочий сценарий: [Студия маршрутов](ROUTE-STUDIO.md).
Действующая граница day/night: [измеренный отказ и приватные варианты](../audits/2026-11-03/DAY-NIGHT-LOCALIZATION.md).
Новый ночной случай, точные причины отказа на кадрах исходника и проверка
старта: [SKUTER1-LIVE-ACQUISITION](../audits/2026-11-03/SKUTER1-LIVE-ACQUISITION.md).

В обеих локальных попытках проверены одинаковые geometry/native-source SHA
и сохранённый preferred ID этого эталона. Файлы исходника, профили и лучшая
геометрия не изменяются ради нового опыта. Больший счётчик камер или точек
сам по себе не разрешает сменить preferred.

Метод эталона — совместные VIDEO/LK и отдельные SIFT-наблюдения, global
mapping, фильтрация целых конфликтующих треков и robust fixed-K BA. Это
не обычный VIDEO-only incremental-проход. История, native-проверки и
сравнения: [сильная геометрия skuter1](../audits/2026-11-03/ROUTE-REACTIVITY-AND-PLACEMENT.md).
Эталон не устанавливает метрическую истину улиц или допуск автономного ввода.

## Локализация по эталону: текущая граница

| Проверка | Фактический результат | Значение для текущей задачи |
| --- | --- | --- |
| Исторический Reference-LK, 12 настоящих дневных JPEG по ночной карте | Все `unknown`, 0 inliers; нейтральный план транспорта | Хорошая 3D-геометрия ещё не обеспечивает day/night acquisition |
| Native RootSIFT на отдельном свежем дневном кадре | `confirming`, 55 inliers, около 140 мс | Один подтверждающий кадр не допускает движение |
| Приватный GPU LightGlue direct512, архив 12 кадров | 4 localized / 6 confirming / 2 unknown; 4.165 Гц в последовательном replay | Это не устойчивая независимая 5-Гц обработка и не завершённый заезд |
| Приватные отрицательные проверки direct512 | 89 unrelated → 89 unknown | Отрицательный набор не заменяет dense day/night-приёмку в движении |

Источник этих измерений — [DAY-NIGHT-LOCALIZATION](../audits/2026-11-03/DAY-NIGHT-LOCALIZATION.md),
включая отдельные протоколы времени и source-bound feature namespaces.
Порог свежести 250 мс, проверка текущего кадра, подтверждение несколькими
изображениями и нейтральный ввод при неизвестной позе сохраняются. Новая
runtime-семья не наследует квалификацию Reference-LK только из-за общей геометрии.

## Продолжение и допуск

Сейчас продолжается day/night-локализация по неизменённому эталону skuter1.
Новый тяжёлый SfM, tail-PnP или повтор GLOBAL skuter2 не запускается вслед за
отказом. Возможный следующий метод skuter2 — отдельный incremental-кандидат
с измеренным moving seed и переиспользованием float-кэшей; это ещё не запуск
и не принятый production-алгоритм.

Для последующего принятого кандидата стандартный путь проходит через
`alternative_geometry.alternative`, `route_preparation_source.resolve_alternative_source`,
`prepare_route_workspace.prepare` и отдельную Reference-LK-квалификацию.
Пять native-файлов, geometry/source-index/capture SHA и полный набор исходных
ракурсов должны совпадать. Состояние `awaiting_qualification` не равно
готовности управления. Неуспешная или непроверенная карта не публикуется
вместо пользовательского эталона.
