# Устройства, потоки и обнаружение: действия оператора

Это руководство описывает основные элементы пяти страниц по исходному коду рабочей
ветки. Результат статической сверки и непройденные проверки приведены в конце;
фактические версия установки, доступ устройства и права определяются отдельно.
Наличие кнопки не подтверждает выполнение команды. Профильные контракты: [каталог
и статусы](DEVICE-CATALOG.md), [запись маршрута](TEACHING-WEB.md), [Route Studio](ROUTE-STUDIO.md),
[действия VPN](VPN-CONTROL-OUTCOMES.md).

## Реестр `/devices`

### Поиск, виды и выбор

| Элемент | Действие и граница |
|---|---|
| Обновить список | Повторно запрашивает каталог; пока запрос выполняется, кнопка недоступна. Ошибка чтения не равна пустому парку. |
| Таблица, карточки, сетка видеопотоков | Меняют представление текущей области. Действия над выделением в сетке скрыты. |
| Поиск, группа, локация, карточки статуса | Сужают серверную выборку; изменение фильтра сбрасывает страницу и выделение. Online и busy — данные состояния API, а не успешная проверка потока. |
| Сброс фильтров | Снимает фильтры группы и локации; поиск и статус на этой кнопке не очищаются. |
| Размер страницы, назад, вперёд | Выбирают 50, 100 или 200 записей; смена размера/страницы очищает выделение. Область выделения ограничена текущей страницей. |
| Выбор строк | Позволяет применить действия к выбранным ID. «Снять выделение» очищает выбор. При изменении результатов исчезнувшие ID удаляются из выделения. |

Кнопка «Устройства» на странице группы открывает реестр с начальным фильтром
`group_id`. В таблице доступна настройка представления и видимых полей; имя
устройства открывает инспектор. Состояние и сроки обновления API описаны в
[каталоге устройств](DEVICE-CATALOG.md).

На текущей странице реестра нет кнопки ручного создания или регистрации
устройства. Запись может появиться через отдельную регистрацию агента; поиск с
необязательной регистрацией описан ниже в разделе `/discovery` вместе с его
ограничениями. Существование серверных endpoints создания и регистрации само по
себе не означает, что они вызываются из этого экрана или что агент уже на связи.

### Изменения и массовые операции

Обычные изменения и перезапуск требуют `device:write`, удаление — `device:delete`,
массовый отзыв VPN — `vpn:mass_operation`. Сервер независимо проверяет доступ и
принадлежность записей. Кнопки могут блокироваться при ожидании запроса, отсутствии
прав или подходящих данных. Лимит массового API — 500 ID за запрос.

| Действие | Что делает интерфейс и что проверить |
|---|---|
| Переименовать | Открывает форму с непустым именем; единичное действие доступно также из меню строки. Ошибка оставляет форму для исправления. |
| Назначить группу | Выберите группу и подтвердите. Привязка заменяет **все текущие группы** каждого выбранного устройства одной выбранной группой; при частичном `moved` выделение сохраняется для проверки. |
| Назначить локацию | Добавляет привязку, не заменяя другие локации. Ответ считает **новые** привязки, а не все уже существовавшие связи. |
| Игровой сервер | В меню строки сохраняет выбранное имя или очищает его; значение относится к записи каталога. |
| Перезапустить выбранные | Отправляет live-команду; при частичном результате остаются выделены устройства с ошибкой. Подтверждение приёма не доказывает завершённую перезагрузку. |
| Отозвать VPN | Требует отдельного подтверждения; при частичном результате остаются выделены неуспешные ID. Удаление пира и фактическое состояние сети Android проверяются отдельно. |
| Убрать устройство | Диалог подтверждения удаляет запись из активного каталога с сохранением истории; это не удаление APK или данных Android. При неподтверждённом ответе сначала проверьте каталог. |

При ошибке обновления реестра интерфейс может показать последний успешный ответ с
предупреждением; он не становится свежим из-за отображения. При загрузке списка
групп или локаций и ошибке их обновления отображаются соответствующие состояния;
ранее полученные значения могут оставаться доступными. Без доступных групп или
локаций соответствующая кнопка назначения отключена.

Переименование в панели выделения предлагается при выборе ровно одного устройства;
сохранение отключено для пустого имени и во время запроса. Назначение группы и
локации требует выбранного значения и непустого выделения. При полном назначении
группы выделение очищается, а при частичном сохраняется для проверки. После
успешного ответа о назначении локации интерфейс очищает выделение независимо от
числа новых связей: уже существующие связи не входят в счётчик, а отсутствующие
в организации ID сервис не добавляет. Сам счётчик и очистка выделения не
подтверждают назначение каждому выбранному устройству; при сомнении проверьте
принадлежность и связи в обновлённых данных.
Массовый перезапуск отправляется сразу по нажатию без дополнительного диалога.
При полном ответе выделение очищается, при частичном остаются ID с ошибкой, при
ошибке самого запроса сохраняется прежний выбор. Перед повтором неполученного
результата необходимо проверить состояние устройств.

Удаление одной или нескольких записей требует подтверждения, отзыв VPN — отдельного
подтверждения. Во время удаления и отзыва повторная отправка блокируется. При
частичном удалении показан счётчик, а оставшиеся записи могут сохраниться
выделенными, если ещё присутствуют в ответе. Отзыв refresh-доступа устройства
указан в подтверждении удаления; реальное восстановление или повторное подключение
зависят от отдельного процесса регистрации. Ошибка сетевого запроса не доказывает,
что на сервере ничего не изменилось.

Источники: [страница реестра](../../frontend/app/%28dashboard%29/devices/page.tsx),
[действия строки](../../frontend/src/features/devices/FleetMatrix.tsx),
[массовое удаление](../../frontend/src/features/devices/DeviceBulkDeleteButton.tsx),
[серверный bulk](../../backend/api/v1/bulk/router.py).

## Карточка `/devices/[id]`

Карточка открывается полностью либо в инспекторе. «Обновить карточку» и переходы
«Реестр» и «Открыть поток» не выполняют жест или перезагрузку. Если API вернул
ошибку после успешного ответа, старый снимок может остаться видимым, но shell,
Logcat, исходный снимок, профиль и перезагрузка из карточки блокируются. Для них
карточка требует успешного ответа после открытия, отсутствия ошибки, возраста не
более 45 секунд и статуса `online` или `busy`. Запрос карточки обновляется каждые
15 секунд. Встроенный viewer проверяет поток и право `stream:control` отдельно:
старый или ошибочный снимок карточки сам по себе не отключает его управление.

| Вкладка или кнопка | Действие и ограничение |
|---|---|
| Обзор | Последние поля API: версия агента, heartbeat, длительность соединения, CPU, память и питание. Отсутствующее значение не следует трактовать как ноль. |
| Задачи / События | До шести последних записей этого устройства, обновление каждые 15 секунд; доступны переходы к соответствующей задаче. |
| Видео | Диагностика захвата, кодера и очереди APK; отдельная ссылка открывает поток с браузерной диагностикой. Принятие кадра очередью не доказывает получение браузером. |
| Логи APK | Последние до 100 ранее доставленных на сервер строк, ручное обновление; доступны при offline, это не живой Logcat. |
| Видеопоток | Открывает viewer; требуется `stream:read`. |
| Записать маршрут | Переход в `/stream/[id]?teach=1`, при `stream:read` и `stream:control`; переход не начинает запись автоматически. |
| Терминал | Последовательные shell-запросы, а не постоянный SSH; требуется `device:write` и свежий reachable snapshot. Закрытие ожидания не отменяет доказанно уже доставленную команду. |
| Logcat | Разовый запрос до 500 последних строк логов Sphere к APK; требуется `device:read` и reachable snapshot. Это не непрерывный системный Logcat. |
| Shell-скрипт | Выполняет непустые строки по одной через HTTP shell; строки с `#` пропускаются, после ошибки выполнение последующих прекращается. Требуется `device:write` и reachable snapshot. |
| Снимок экрана | Запрашивает исходный PNG Android через APK/root. Размер, принадлежность, заголовки и SHA-256 сверяются до скачивания; ошибка cleanup показывается отдельно. Это не PNG из декодированного видео. |
| Системный профиль Android | Отдельный ручной запрос APK при `device:write` и reachable snapshot; отсутствие ответа не подменяется выдуманными значениями. |
| Перезагрузка | Диалог подтверждения и одна live-команда. Ответ о принятии не означает, что Android уже загрузился; проверяйте последующие heartbeat. |
| Изменить запись в реестре | Переход к реестру, где доступны переименование и назначение. |

При первой загрузке карточка показывает ожидание; если подтверждённого ответа нет,
предлагает повторить запрос. Если ошибка возникла после успешного ответа, виден
предыдущий снимок с предупреждением. Он не разрешает перечисленные выше команды
карточки. Переход к видеопотоку проверяет `stream:read` отдельно и не гарантирует работоспособность
видео. Запись маршрута предлагается только при `stream:read` и `stream:control`.

Снимок экрана и системный профиль требуют `device:write` и свежего доступного
снимка карточки. «Получить снимок» отключена во время запроса; после ошибки может
оставаться предыдущий успешно полученный PNG. Нового автоматического запроса нет.
В предпросмотре можно выбрать «Вписать в панель» или «100% · 1:1», скачать
проверенный файл; неподтверждённая очистка временных файлов Android показывается
отдельно. Профиль читается вручную последовательными разделами и прекращает
чтение при первой ошибке, сохраняя ранее полученные разделы. Сетевые интерфейсы
профиля не подтверждают внешний IP или IP выхода VPN.

Перезагрузка открывает диалог с «Отмена» и подтверждением. Пока ожидается ответ,
диалог нельзя подтвердить повторно или закрыть этой отменой. Ответ
`reboot_initiated` подтверждает принятие команды, а не завершение загрузки;
при неизвестном результате следует проверить последующие heartbeat до повтора.
История, диагностика и сохранённые логи показывают загрузку и ошибки отдельно от
пустого результата; кэшированные данные при ошибке могут быть устаревшими.

Источник: [карточка](../../frontend/src/features/devices/DeviceInspectorDetail.tsx),
[история и диагностика](../../frontend/src/features/devices/DeviceOperationsPanels.tsx),
[исходный снимок](../../frontend/src/features/devices/NativeScreenshotPanel.tsx),
[терминал](../../frontend/src/features/devices/WebTerminal.tsx),
[последовательный shell](../../frontend/src/features/devices/RunScriptTab.tsx).

## Видеостена `/stream`

Список использует размер сетки как размер страницы: 1, 2, 4, 6, 9, 12, 16, 25,
32 или 64. Поиск, группа, локация, статус и страницы определяют видимую область;
сортировка текущих загруженных устройств доступна по имени, статусу, модели,
батарее и последней связи. «Обновить список» повторяет запрос. Ошибка получения
каталога и пустая выборка показываются отдельно.

На плитке нажмите «Смотреть» для явного запуска viewer, «Стоп» — для его остановки;
«Остановить просмотр» очищает выбранные для просмотра потоки. Для недоступного по
статусу устройства кнопка запуска отключена. Значение heartbeat или online не
доказывает получение видео; при проблеме смотрите состояние viewer. Размер сетки
не является гарантией производительности такого числа одновременных потоков.
[Исходник видеостены](../../frontend/app/%28dashboard%29/stream/page.tsx).

Для запуска по статусу пригодны `online` и `busy`; `busy` означает, что
устройство занято работой, а не что оно свободно для ручного ввода. При ошибке
повторного чтения могут остаться ранее загруженные плитки и время последнего
успешного ответа API. Их статусы могут устареть: доступная кнопка «Смотреть»
на таком снимке не подтверждает текущее состояние устройства или подключение.
При сообщении о недоступном live-presence дождитесь восстановления состояния.
Каталоги группы и локации загружаются отдельно; отсутствие варианта в фильтре
само по себе не подтверждает отсутствие группы или локации.

Плитки видеостены открываются **только для просмотра**, даже если у пользователя
есть права управления. На выбранной плитке доступна диагностика и чтение качества;
изменение качества, навигация Android и снимок кадра здесь не включены. При
временной потере доступного статуса выбранный просмотр приостанавливается и
возобновляется при возвращении устройства в текущую выборку. Скрытие фильтром
или переход на другую страницу закрывает viewer, но сохраняет выбор до явной
остановки. Счётчик «Остановить просмотр» относится к выбранным ID, в том числе
временно скрытым, а не только к текущим подключённым сокетам.

## Поток `/stream/[id]`

Страница открывает отдельный viewer и ссылку в карточку. `stream:read` нужен для
маршрута просмотра, `stream:control` — для ввода; при отсутствии управления поток
работает в режиме чтения. «Записать маршрут» переключает на `?teach=1`, «Обычный
поток» возвращает обычный экран. Подробный процесс записи и тестов — в
[Teaching Web](TEACHING-WEB.md) и [Route Studio](ROUTE-STUDIO.md).

| Элемент | Назначение и граница |
|---|---|
| Экран | При готовом и разрешённом вводе передаёт действия; картинка и команда имеют разные подтверждения. Не повторяйте жест автоматически после неизвестного результата. |
| Сохранить кадр видео | Экспортирует декодированный кадр в PNG, возможно с потерями относительно оригинала Android. Для исходного PNG используйте карточку устройства. |
| На весь экран / выход | Меняет отображение в браузере; кнопка недоступна без поддержки fullscreen. В полноэкранном режиме панель Android можно показать или закрепить отдельной кнопкой, мышью у нижнего края либо фокусом. |
| Качество видеопотока | Читает настройки Android; пресеты и поля FPS/битрейта формируют запрос, «Применить» сохраняет его при наличии управления. Настройки влияют на всех зрителей. Если ответ потерян, сначала перечитайте состояние: настройки могли примениться. Целевые FPS не являются измеренными FPS. |
| Диагностика | Показывает сведения транспорта и ввода; закрытие панели не означает остановку viewer. |
| Назад, Домой, Недавние, Меню | Отправляют отдельные системные команды Android только при готовом вводе. |
| Клавиатура и текст | Дополнительные клавиши редактирования и ввод текста. Статусы «подтверждено», «не отправлено» и «результат неизвестен» различаются; неизвестный ввод повторно не отправляется автоматически. |
| Восстановить управление | Появляется для определённых закрытых/ограждённых состояний; повторное согласование не доказывает результат прежнего жеста. |

### Видео и доступность действий

- Во время подключения показывается ожидание; если первый кадр не пришёл за
  10 секунд, интерфейс сообщает об этом. После разрыва последняя картинка может
  оставаться видимой во время переподключения: она сама по себе не разрешает
  управление в новой сессии. Необходим кадр, успешно отрисованный текущей
  сессией, и открытое соединение.
- В одиночном viewer при отсутствии новых кадров более 10 секунд управление
  может работать по последнему кадру текущей сессии. Это полезно для неподвижного
  экрана, но не доказывает актуальность изображения; PNG из видео для `stale`
  отключён. Ошибка, разрыв, инспекция, read-only, занятый ввод задания или
  неподтверждённое освобождение блокируют новые действия. Сообщение можно скрыть,
  но это не восстанавливает право ввода. [Подробнее](STATIC-STREAM-INPUT.md).
- Сводка показывает текущий выбранный транспорт, разрешение, FPS и битрейт при
  наличии измерений. Прямое видео само по себе не подтверждает готовность прямого
  управления. Сетевой RTT и время подтверждения команды не измеряют задержку
  появления изменения на экране.
- В полноэкранном режиме панель Android находится поверх нижней части видео;
  она открывается наведением, фокусом или переключателем. Выход из fullscreen
  меняет только представление. Поддержка зависит от браузера.
- При готовом вводе щелчок и перетаскивание по изображению отправляют касание
  или свайп. Колесо мыши над видео может отправить короткий вертикальный либо
  горизонтальный свайп; модификаторы Ctrl или Meta оставляют это сочетание
  браузеру. Эти действия недоступны в режиме только просмотра и не следует
  считать подтверждёнными по одному движению указателя.

### Настройки качества

Открытие окна читает настройки с Android. При чтении показывается загрузка; при
ошибке — сообщение о связи или версии APK. Неподдерживаемый APK предлагает
обновление. Доступны профили «Авто», «Высокая детализация», «Экономия трафика»
и быстрые пресеты «Авто», «Текст», «Скан · 30 FPS», «LAN · 60 FPS», «Экономия».
Пресет заполняет форму, но не применяет её без отдельного нажатия.

FPS задаётся целым числом от 1 до 60, битрейт — от 0,1 до 32 Мбит/с; пустые поля
оставляют автоматический выбор. «Применить» недоступна в режиме чтения, во время
запроса, при ошибке валидации и пока форма не отличается от прочитанного снимка.
«Обновить» перечитывает настройки и заменяет черновик. Подтверждённый ответ
показывает сохранённые Android настройки; при потерянном ответе результат неизвестен,
поэтому перед новой попыткой выполните чтение. Настройки общие для зрителей, а
цели кодека не гарантируют фактические FPS или пропускную способность.

### Клавиши, текст и запись маршрута

Кнопки «Назад», «Домой», «Недавние», «Меню» и дополнительные клавиши блокируются
до готовности управления и на время ожидаемой команды. Система показывает
ожидание, подтверждение, «не отправлено» или «результат не подтверждён». После
неизвестного результата проверьте экран до следующего ручного действия; повтор
не выполняется автоматически. При доступности используется согласованный native
key, иначе предусмотрен shell-путь с отдельными правами и ограничениями.
[Навигация Android](ANDROID-NAVIGATION.md).

«Клавиатура и текст» содержит отдельное поле с ограниченным ASCII-вводом до 1024
символов и кнопки работы с буфером **Android**; буфер браузера — отдельный.
Кириллица, emoji, переносы строк и неподдерживаемые служебные символы этим полем
не отправляются. Отдельный переключатель аппаратной клавиатуры использует готовый
совместимый канал управления: при фокусе на видео возможны поддержанные нажатия,
вставка и ввод в выбранное поле Android. При отсутствии канала или активного
поля показывается соответствующее состояние; автоматически повторять ввод после
неизвестного результата нельзя. На сенсорном экране кнопка «Печатать» появляется
при готовом поле. Поддержка ввода зависит от APK и браузера.

Аппаратная клавиатура работает через сфокусированную область удалённого ввода,
а не перехватывает набор текста по всей странице. При её готовности щёлкните
по видео и выберите поле на Android. `Ctrl+V` / `Cmd+V` используют событие
вставки браузера для отправки текста, а кнопка «Вставить в Android» работает
с буфером самого Android. Вставка через клавиатурный канал ограничена 1024
единицами длины JavaScript за раз; неподдерживаемый текст отклоняется. При
потере фокуса или скрытии страницы клиент сбрасывает локальное состояние и
запрашивает освобождение удерживаемых клавиш; это не подтверждает результат
уже отправленного ввода или освобождение на устройстве.

Ссылка «Записать маршрут» открывает студию, но запись не запускает. В студии
сначала подключите поток; без `stream:control` подключение и запись недоступны.
«Включить управление» и «Записать маршрут» доступны только в соответствующей
готовой фазе, при исправной схеме управления и без активной калибровки.
Режим управления в эмуляторе записывает только видео: внешние нажатия не
попадают в журнал. При веб-управлении отдельно записываются подтверждённые
действия. «Остановить · Esc» инициирует освобождение и сохранение, а не
мгновенно подтверждает результат: дождитесь статуса «Сохранена» либо причины
неполной записи. Переключение разделов заблокировано во время активной операции;
видео и журнал не подтверждают автоматический повтор пути. Подробные условия,
калибровка и ограничения — в [Teaching Web](TEACHING-WEB.md).

### Диагностика

Кнопка открывает и закрывает панель без остановки видео. Она отдельно показывает
состояние ввода, транспорт, локальные счётчики APK, браузерное декодирование и
доступные сетевые метрики. Локальное принятие кадра очередью APK не подтверждает
его получение браузером. История показывает до 10 сеансов; загрузка, ошибка и
пустой список различаются. Это метрики и события, а не видеозапись. Если прямое
видео не допущено и соблюдены условия, может выполняться автоматическая проверка;
её результат и текущий просмотр следует оценивать отдельно.

Встроенный viewer карточки также предлагает режимы «Управление», «Просмотр» и
«XPath-инспектор». Инспектор требует `device:write`, готовой геометрии и освобождённого
ввода; «Обновить дерево», автообновление, выбор элемента и копирование XPath не
являются нажатием Android. Snapshot имеет ограниченный срок; UI Automator может не
раскрыть элементы игры на Canvas. Подробности: [контракт инспектора](../audits/2026-10-04/UI-HIERARCHY-INSPECTOR.md).

## Поиск `/discovery`

Маршрут и серверный поиск требуют `device:write`. Переход «Открыть парк устройств» ведёт в реестр. Для дополнительного ADB-поиска
укажите CIDR, UUID **существующего** PC Agent, две границы портов 1–65535 и таймаут
100–5000 мс. Кнопка «Начать поиск» блокируется при незаполненном UUID или неверных
портах/таймауте; CIDR дополнительно проверяет сервер. Переключатель регистрации в
веб-форме **выключен по умолчанию**: при включении запрос может добавить записи.
При прямом API-вызове `auto_register` по умолчанию, напротив, `true` — передавайте
его явно.

По умолчанию форма содержит `192.168.1.0/24`, порты `5554,5584` и таймаут
500 мс. Во время запроса повторная отправка отключена. Результат показывает
параметры отправленного запроса, время ответа, найденные и добавленные записи,
адрес, порт, serial, модель и состояние регистрации. Backend вычисляет `scanned`
из размера подсети и диапазона портов: это объём запроса, а не доказанное число
фактически проверенных соединений. Ответ с неверной структурой считается ошибкой.

После ошибки «Повторить исходный поиск» повторяет параметры именно неудавшегося
запроса, включая регистрацию; не путайте его с отправкой текущей изменённой формы.
При просмотренной ревизии backend отправляет команду `discover_adb`, которая не
реализована текущим dispatcher PC Agent; ошибка или timeout могут быть преобразованы
сервером в пустой список. Поэтому надпись «Устройства не найдены» **не подтверждает**,
что сеть реально просканирована или устройств нет. Сравнивайте с диагностикой PC
Agent и фактической сетью, не с сетевой доступностью только backend.
